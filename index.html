这是一个更完整的主题切换演示页：支持手动切换浅色 / 深色模式，
自动记住你的选择，并跟随系统主题首次启动。

动态主题变量

通过 CSS 变量统一控制背景、文字、卡片和按钮颜色，切换更干净。

⚡

平滑过渡动画

所有主题变化都带有缓动过渡，避免生硬闪烁，整体更有高级感。

💾

本地记忆状态

使用 localStorage 保存用户选择，刷新页面后仍保留上次主题。

功能说明

点击右上角主按钮，可以在浅色模式和深色模式之间切换。页面会根据当前主题自动调整背景渐变、卡片透明度、文字对比度和按钮阴影。 如果希望恢复系统默认，可以点击“跟随系统”按钮清除本地记忆。
