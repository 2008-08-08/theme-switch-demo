# Theme Switcher Demo
> 开源 × Vibe Coding 赛道自主项目
> 用AI辅助开发的网页明暗主题切换组件，纯前端实现，开箱即用。

## ✨ 项目简介
本项目是基于HTML/CSS/JavaScript开发的网页主题切换Demo，由AI辅助完成设计与代码实现。
实现浅色/深色主题一键切换，支持自动跟随系统主题，记忆用户偏好，搭配玻璃拟态UI、渐变背景与流畅动画。

## 🚀 功能特性
- ✅ 一键切换浅色 / 深色模式
- ✅ 本地存储记忆用户主题选择，刷新页面不丢失
- ✅ 一键重置，跟随操作系统原生主题
- ✅ 实时状态面板，展示当前主题、系统主题、存储状态
- ✅ 玻璃拟态卡片、渐变背景、hover上浮动画
- ✅ 响应式布局，手机/电脑均可正常浏览
- ✅ CSS变量统一管理主题色彩，易于二次扩展
